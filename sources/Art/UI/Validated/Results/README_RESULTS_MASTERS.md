# Masters Résultats validés

## RESULTAT_INTERMEDIAIRE_BRAVO_MASTER.png

Usage : résultat intermédiaire.

Statique : panneau, pictogrammes, titres et visuel CONTINUER.

Dynamique Godot :
- Score
- Temps : Référence et Réalisé uniquement
- Ratio Réussite : pourcentage dans l’anneau, Réalisé et points

Le bouton graphique CONTINUER est intégré au PNG. Godot ajoute uniquement une
hitbox transparente reliée au handler historique.

## FIN_CAMPAGNE_BRAVO_MASTER.png

Usage : fin de campagne.

Statique : panneau, pictogrammes, titres et flèche Retour.

Dynamique Godot : Score, Temps (Référence et Réalisé), Ratio Réussite, Niveau,
Niveau Parfait et Bonus Campagne.

Le wording est figé à « Niveau Parfait ». Aucun bouton Continuer n’est présent.
La flèche Retour utilise une hitbox transparente native.

## PERDU_MASTER.png

Usage : écran PERDU.

Écran 100 % statique : aucune valeur dynamique et aucun Label Godot à ajouter.
Le PNG contient PERDU, le visuel et CONTINUER. Godot ajoute uniquement la
hitbox transparente du bouton Continuer.
